Lý thuyết bảo vệ

Cơ sở lý thuyết trào lưu công suất & quy chuẩn vận hành (Defense Aid)

1. Quy chuẩn điện áp vận hành (EVN / IEEE Std 399)

  • Chế độ bình thường (N-0): Điện áp thanh cái phải nằm trong dải 0.95 pu ≤ V ≤ 1.05 pu (sai lệch ±5%).
  • Chế độ sau sự cố đơn lẻ (N-1): Điện áp phục hồi cho phép trong dải 0.90 pu ≤ V ≤ 1.10 pu (sai lệch ±10%).
  • Góc lệch pha truyền tải: Độ lệch pha giữa 2 đầu đường dây Δθ ≤ 30° để đảm bảo dự phòng ổn định công suất tĩnh.

2. Phân loại 3 loại nút trong lưới điện

  • Slack Bus (Cân bằng): Biết trước |V|, δ = 0°. Thuật toán tìm P_g, Q_g gánh toàn bộ tổn thất công suất.
  • PV Bus (Máy phát): Biết trước P_g, |V_set|. Thuật toán tìm δ, Q_g.
  • PQ Bus (Phụ tải): Biết trước P_d, Q_d (tức P_net = -P_d, Q_net = -Q_d). Thuật toán tìm |V|, δ.
  • Chuyển đổi PV ➔ PQ: Khi Q_g chạm ngưỡng giới hạn [Q_min, Q_max], nút PV chuyển thành PQ với Q ghim cố định và |V| biến thiên tự do.

3. Hệ phương trình trào lưu công suất xác lập

ΔPi = Pispec − Vi Σk=1N Vk (Gik cos θik + Bik sin θik) = 0

ΔQi = Qispec − Vi Σk=1N Vk (Gik sin θik − Bik cos θik) = 0

4. Tuyến tính hóa qua ma trận Jacobian

[ ΔP ]   =   [ H    N ]   [ Δθ ]
[ ΔQ ]         [ M    L ]   [ ΔV / V ]
  • H = ∂P / ∂θ, N = ∂P / ∂(ln V) = V (∂P / ∂V)
  • M = ∂Q / ∂θ, L = ∂Q / ∂(ln V) = V (∂Q / ∂V)
  • Điều kiện dừng hội tụ bậc hai (Quadratic Convergence): ||ΔP, ΔQ||_∞ < 10⁻⁶ pu.
